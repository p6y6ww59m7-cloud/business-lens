# 生意透镜

输入一段业务介绍，AI 判断「产品、营销、人群」九个小项各自属于哪一种主要方向，并推荐接下来可以做的内容选题。缺关键信息时再追问。

**[打开网页](https://p6y6ww59m7-cloud.github.io/business-lens/)** · [下载整个项目](https://github.com/p6y6ww59m7-cloud/business-lens/archive/refs/heads/main.zip) · [下载独立 HTML](https://github.com/p6y6ww59m7-cloud/business-lens/releases/latest/download/business-lens.html)

## 打开就能看

网页和下载后的 `index.html` 都能独立打开。里面有完整示例、九项框架和可复用的分析方法。查看示例不需要调用 AI，也不需要安装依赖。

每次打开页面都会询问是否允许连接**访问者自己的本机 Codex**。不允许仍可查看示例和已有报告。本站没有共享的 Codex 账号，不接收访问者的 Codex 登录凭据。

## 使用 AI

首次使用需要在自己的电脑上装好 Node.js（22.13 以上）和 Codex，并完成 Codex 登录。

1. 下载整个项目并解压，保持文件夹完整。
2. Mac 双击 `启动生意透镜.command`；Windows 可使用 `启动生意透镜.cmd`。
3. 回到网页，选择连接本机 Codex，在打开的本机确认窗口里点“允许”。确认窗口保持打开。
4. 输入业务介绍，开始分析；回答追问后可以继续分析。

也可以在项目目录运行 `node server/launch.mjs`。如果浏览器拦截了确认窗口，需要允许本站弹出窗口。默认本机地址为 `http://127.0.0.1:49321`；地址变化时，可在连接对话框中修改。

Mac 连接已实测。Windows 启动脚本已提供，尚未在真实 Windows 设备上测试。手机或没有本机 Codex 的设备可以查看页面和示例。

## 授权与资料

- 授权需要在本机确认页点击，网页不能自动替用户同意。
- 关闭确认窗口或点击“断开本页连接”，本次授权结束；重新打开网页会重新询问。
- 连接程序只监听本机回环地址。在线网页通过受来源和窗口校验的消息与本机确认窗口通信，不开放跨域 HTTP 调用。
- 业务资料通过访问者自己的 Codex 发给 AI，使用其账号的可用权限和额度；需要联网。
- 草稿暂存在当前浏览器，可用“保存资料”下载 JSON 备份。报告可以导出为可独立打开的 HTML。
- 生成的 HTML 和导出报告不包含登录凭据。仓库中的业务数据为虚构示例。

## 分析内容

| 产品 | 营销 | 人群 |
| --- | --- | --- |
| 产品有哪些、主要利润来自哪个 | 公域三种变现形式 | 消费心理账户 |
| 主产品解决谁的什么需求 | 五类 IP 业务形态 | 消费心理旅程 |
| 独特成交理由与护城河 | 完整触达销转链路 | 人群需求场景 |

每个小项只给一个主要归属方向和简短说明，例如变现形式为「线索获客」、IP 业务形态为「知识付费」，不罗列全部可选类型。依据按需展开。

最后推荐三至五个具体选题：标题、大概讲什么、主要解决什么问题。可行性、获客成交和同行借鉴等深入判断放在可展开的补充区域，保持主画面简洁。

## 开发

运行工具不需要 npm 安装。开发和测试使用：

```sh
npm ci
npm run build:html
npm test
```

`web/` 是页面与分析协议源文件；`server/` 是本机连接和 Codex 调用；`index.html` 是可独立打开的产物；`docs/index.html` 供 GitHub Pages 发布。修改源文件后需重新构建并提交两个 HTML。

Codex 每次分析在临时目录中以只读、临时会话运行；关闭命令执行、应用插件、个人记忆、子代理和 hooks，只使用输入资料及允许的公开检索。调用结果经九项报告结构校验，临时输出读取后删除。不修改用户已有的 Codex 配置。

参考：[Codex 非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode)、[跨窗口消息校验](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage)。
