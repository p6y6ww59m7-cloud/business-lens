需要什么材料？

  • 产品介绍、价格、交付方式。
  • 谁使用、谁付钱，什么场景下需要。
  • 获客渠道和从看到你到付款的步骤。
  • 有则提供：成本、成交和未成交记录。
  • 同行的产品、价格、做法与原始来源。

没有的可以留空，不用补编数据。

按什么顺序问？

  1. 先说清具体生意和经营阶段。
  2. 问卖什么、帮谁解决什么问题。
  3. 问为什么选你、怎样找到客户。
  4. 问客户怎样理解价格、怎样决定。
  5. 最后补成本、同行和证据。

你会得到什么？

  • 三栏九项，每项一个主要归属方向。
  • 推荐选题、主要讲什么及内容目的。
  • 值不值得做、获客成交怎么改。
  • 同行有哪些值得学，适合什么条件。
  • 一个成交或流失判断及其依据。
  • 下一步优先做什么、怎么验证。
分清三件事：已经提供的信息、根据材料作出的推断、还要验证的假设。
AI 会根据你提供的资料分析；需要核实当前市场、同行或规则时，优先查看公开原始来源。资料不足时，不编造数据。
资料只在当前浏览器暂存。请用“保存资料”下载备份，移动 HTML 文件或清理浏览器后，暂存资料可能无法恢复。

是否连接这台电脑的 Codex？

允许后，使用访问者自己电脑上已登录的 Codex 分析业务资料。不会共用网站作者的账号，也不会把 Codex 登录凭据交给网页。
